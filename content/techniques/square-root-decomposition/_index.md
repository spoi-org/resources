Square-root decomposition is an incredibly elementary technique that can solve a surprising variety of problems, including range queries.

Surprisingly, there's very little to learn for the core idea. We will start by solving some simple problems (like point update range sum), and, later on, we'll explore more advanced applications of square-root decomposition (periodic rebuilding).
